# library-management-system
Simple Python Tkinter Library Management System
📚 Library Management System

A simple Python Tkinter GUI-based Library Management System for managing books and lending operations.

🚀 Features
Add books (Title, Author, ISBN, Fee, Quantity)
Search books by title or author
Borrow books (auto quantity reduction)
Return books with late fee calculation (after 14 days)
View inventory report
Simple and user-friendly GUI
🖥️ Technologies Used
Python
Tkinter (GUI)
Datetime module
▶️ How to Run
Install Python (>=3.x)

Download or clone this repository:

git clone https://github.com/YOUR_USERNAME/library-management-system.git

Navigate to the folder:

cd library-management-system

Run the program:

python library_system.py
